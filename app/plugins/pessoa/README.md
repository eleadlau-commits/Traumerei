# Pessoa

A way of seeing a room: every thought on its own, laid on a loose spiral outwards in the order it
was written, and left where it is dragged. It makes no groups: another rule's group shows as one
thought, in the tray until it is dragged out. Its new thoughts join Joyce's trains while Joyce is on
(`writesInto`), else they wait loose. A room whose own rule is off is seen through Pessoa while it
is on (`seesAll`).

A corpus plugin (open core step 1a): built in and on. It adds one rule (`t.slots.rules`);
`rules.js` is the rule, `world.js` what it uses of the plugin API's parts. It keeps no data.
